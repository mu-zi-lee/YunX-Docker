Gopeed 官方包选择已改为 Windows / macOS / Linux 和 amd64 / arm64 / 386 的明确映射。
安装使用临时文件后原子替换，失败保留旧内核；Unix 内核设置当前用户执行权限。
Mac 当前包仍不包含或自动获取内核，不能据此宣称磁力功能可用。

完成标准仍包括可安装包、原生操作、Docker 构建与部署、真实账号验证。
没有账号、签名证书或对应系统时，要保留明确的未验收记录。
本地测试和接口模拟不能替代这些检查。
