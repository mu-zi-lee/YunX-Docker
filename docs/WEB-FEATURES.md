# Web 与 Windows 功能对照

v0.2.0 将网页扩展为网盘工作台。Space Grotesk、Space Mono 和 Lucide 随镜像离线提供，
同时支持浅色、OLED 黑色与跟随系统；移动端使用底部导航。

| 功能 | Web v0.2.0 | 复用或差异 |
| --- | --- | --- |
| 页面登录、退出 | 已实现 | HttpOnly/SameSite 会话，登录限流，12 小时有效，重启需重新登录 |
| 首次随机密码 | 保留 | 自动迁移 v0.1.0 的初始密码 |
| 修改密码 | 已实现 | PBKDF2 哈希持久化，修改后旧会话失效；环境变量管理密码时禁止网页修改 |
| 网盘账号 | 已实现 | 凭证不回显；已配置账号独立展示，未配置平台放在添加入口 |
| 昵称与空间用量 | 已实现 | 复用 Windows QuotaInfo 接口；空值表示未知，读取失败不等同账号失效 |
| 个人网盘目录 | 已实现 | 夸克、UC、百度、139、115、123、光鸭、迅雷；迅雷需要 App 凭证 |
| 目录分页 | 按接口提供 | 夸克/UC/115 页码、139/123 游标；迅雷保留现有 API 的列表限制 |
| 文件操作 | 已实现 | 面包屑、当前目录名称搜索、排序、列表/网格视图、逐文件多选加入下载 |
| 分享解析 | 保留并重做 | 同一文件浏览器，继续复用分享仓库与下载请求头逻辑 |
| 收藏、解析历史 | 已实现 | 复用桌面版 SQLite DAO；保留最近 100 条成功解析记录，可移除 |
| 下载任务 | 已实现 | 速度汇总、状态筛选、暂停全部/继续全部、断点续传、移除记录保留文件 |
| 下载设置 | 已实现 | 线程数、并发数、总限速，加密配置持久化 |
| 自动刷新 Cookie | 保留并扩展 | 夸克/UC 的上游 Set-Cookie 回写；手动更新账号会使旧浏览会话失效 |
| 整文件夹下载 | 尚未移植 | 需要带路径的递归遍历、取消和进度接口 |
| 云端创建/改名/移动/删除 | 尚未移植 | 涉及不同平台的批量、转存任务和确认行为，本版提供读取与下载 |
| 扫码/短信/内嵌登录 | 尚未移植 | Windows JCEF 与本地浏览器 Cookie 导入不能直接运行在 NAS 网页中 |
| Gopeed / 磁力 | 尚未移植 | 当前引擎管理固定 Windows exe；需要 Linux 双架构引擎与独立生命周期 |
| 托盘、系统通知、剪贴板监听 | 不适用 | 依赖 Windows 桌面环境 |

验证分为本地协议/模拟源测试、浏览器视觉与操作测试、双架构容器测试。
容量、风控、真实网盘下载和具体 NAS 设备仍须使用真实账号在部署环境验收。
